# Словник даних

## Таблиця account
Опис: Фінансові рахунки користувача (банківські картки, готівка тощо)
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний ідентифікатор рахунку |
| name | text | так | | Назва рахунку |
| balance | numeric(12,2) | так | | Поточний грошовий баланс рахунку |
| app_user_id | integer | так | FK app_user.id | Посилання на користувача-власника |

## Таблиця app_user
Опис: Користувачі мобільного додатку обліку фінансів
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний числовий ідентифікатор користувача |
| email | text | так | UK | Електронна пошта для входу |
| password_hash | text | так | | Хеш пароля користувача |
| full_name_first_name | text | так | | Ім'я користувача |
| full_name_last_name | text | так | | Прізвище користувача |

## Таблиця category
Опис: Категорії обліку фінансових операцій (доходи або витрати)
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний ідентифікатор категорії |
| title | text | так | | Назва категорії витрат або доходів |
| kind | text | так | | Тип категорії (INCOME або EXPENSE) |

Обмеження CHECK:
- `kind IN ('INCOME', 'EXPENSE')`

## Таблиця profile
Опис: Персональні налаштування та профіль користувача
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний ідентифікатор запису профілю |
| default_currency | text | так | | Основна валюта обліку (наприклад UAH, USD) |
| locale | text | ні | | Мовна локаль інтерфейсу |
| app_user_id | integer | так | FK app_user.id, UK | Зовнішній ключ на користувача |

## Таблиця receipt_item
Опис: Деталізація позицій у фіскальному чеку фінансової операції
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| transaction_id | integer | так | PK, FK transaction.id | Зовнішній ключ на операцію (власник) |
| item_no | integer | так | PK | Порядковий номер позиції у чеку |
| item_name | text | так | | Найменування придбаного товару чи послуги |
| price | numeric(12,2) | так | | Вартість одиниці або позиції товару |

Обмеження CHECK:
- `price >= 0`

## Таблиця tag
Опис: Теги та мітки для зручної фільтрації фінансових операцій
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний ідентифікатор мітки |
| name | text | так | UK | Текстова назва тегу |

## Таблиця transaction
Опис: Журнал здійснених фінансових транзакцій
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| id | integer | так | PK | Унікальний номер транзакції |
| amount | numeric(12,2) | так | | Сума операції |
| transacted_at | timestamptz | так | | Точна дата й час проведення операції |
| note | text | ні | | Необов'язкова примітка або коментар |
| account_id | integer | так | FK account.id | Рахунок списання або зарахування |
| category_id | integer | ні | FK category.id | Категорія фінансової операції |

Обмеження CHECK:
- `amount > 0`

## Таблиця transaction_tag
Опис: Проміжна сполучна таблиця для зв'язку транзакцій та міток
Нормальна форма: BCNF

| Стовпець | Тип | Обов'язковий | Ключі | Опис |
| --- | --- | --- | --- | --- |
| transaction_id | integer | так | PK, FK transaction.id | Зовнішній ключ на транзакцію |
| tag_id | integer | так | PK, FK tag.id | Зовнішній ключ на мітку |
