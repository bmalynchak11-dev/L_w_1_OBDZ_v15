# Наскрізний проєкт

У цій теці живе база даних вашого дипломного проєкту (тему обираєте самі) на весь предмет. Вона складається з трьох файлів:

- `er_model.json` — ER-модель у форматі, описаному в розділі 6 інструкції;
- `schema.sql` — скрипт PostgreSQL, який створює всі таблиці;
- `data_dictionary.md` — словник даних: опис кожної таблиці й кожного стовпця, нормальна форма таблиці.

Перевірка: `pytest project_check` (потрібен запущений PostgreSQL). Фіксуйте кожен етап окремим комітом у Git.
Наступні лабораторні роботи продовжують цей проєкт: додають дані, запити, транзакції та індекси.
